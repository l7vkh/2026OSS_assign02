## Weekly Review

### Key Learning
- Html의 전반적인 구조를 이해하고, CSS를 통해 style을 만들어 레이아웃, 색상, 폰트 등 자유롭게 변경하여 스타일 생성
### HTML vs CSS
- HTML로서 텍스트나 헤더, div를 사용해서 기본적인 사이트의 틀을 구성하고, css를 통해 각각의 영역과 구성원을 디자인하여 원하는 사이트의 디자인으로 제작.
### Bootstrap 사용법
- 사이트에서 일부 부분을 우클릭하여 검사버튼 활성화, (Window는 F12 버튼을 눌러서도 가능) 사이트의 html 코드를 확인 가능, 명령어 참고나 연결방식, parent와 child 노드의 코드까지 분석 가능

- Problem : styleheet1,2를 카피하는 과정에서, menu 박스 자체가 하이퍼링크로 작동하는 버튼 형식임을 확인, 구현 방법의 어려움 발생
- Solution : menu의 li text를 하이퍼링크 형식으로 변경해서 임시 하이퍼링크 생성. 그러나 영역 자체가 버튼이 된 시트와는 다르게, 구현에서 다소 차이점 발생. 추후 추가 학습으로 버튼 구현 시도 예정.
